1. PROJECT OVERVIEW
-------------------
This project is an end-to-end Tropical Cyclone Analysis & Forecasting System. 
It combines satellite computer vision and historical trajectory machine learning 
to perform two primary tasks:

1. Intensity Nowcasting (Current Status): Analyzes multi-channel satellite 
   images (Infrared, Water Vapor, Visible, Passive Microwave) to determine if a 
   cyclone is present, classify its intensity into official IMD categories, 
   and estimate its maximum sustained wind speed (in km/h).
2. 24-Hour & 48-Hour Track Forecasting: Predicts where the cyclone will 
   travel over the next 24 and 48 hours (Latitude, Longitude coordinates), 
   its compass heading direction, and distance traveled.

3. BEGINNER-FRIENDLY CONCEPT GLOSSARY
--------------------------------------
- Nowcasting: Estimating the CURRENT state of the weather right now from 
  live satellite observations.
- Forecasting: Predicting the FUTURE state (e.g., 24 or 48 hours from now).
- Convolutional Neural Network (CNN): A deep learning model that scans satellite 
  image pixels, detects cloud patterns, storm eyes, and spiral bands, and 
  extracts features automatically.
- Classification Head: The output layer of the neural network that assigns the 
  storm into one of 7 official intensity categories (e.g., Depression, Cyclonic 
  Storm, Super Cyclonic Storm).
- Regression Head: The output layer of the neural network that predicts a 
  continuous numerical number (e.g., Wind Speed = 145.5 km/h).
- Early-Fusion Preprocessing: Combining multiple satellite channels (Infrared + 
  Water Vapor + Visible + Microwave) into a single 4-channel tensor before 
  feeding it into the CNN.
- Lag Features: Using past historical records (e.g. location 6 hours ago, 12 
  hours ago) as input features to predict future motion.
- Haversine Distance: A mathematical formula used to calculate real-world 
  distance in KILOMETERS between two points on the curved surface of the Earth 
  using latitude and longitude.

5. HOW EVERYTHING WORKS (STEP-BY-STEP WORKFLOW)
------------------------------------------------
Step 1: Input Data Intake
- User/API uploads satellite imagery (IR, WV, VIS, PMW) and/or inputs current 
  and historical cyclone latitude & longitude points.

Step 2: Satellite Image Preprocessing (app/core/preprocessing.py)
- Resizes uploaded images to 224x224 pixels, normalizes pixel intensity values 
  between 0 and 1, and stacks channels into a 4-channel tensor (1, 4, 224, 224).

Step 3: Intensity Nowcast CNN Inference (app/models/inference.py)
- Passes 4-channel tensor through 4 Conv2D + BatchNorm + MaxPool layers.
- Classification Head predicts intensity category probabilities via Softmax.
- Regression Head predicts max wind speed in km/h.

Step 4: Track Feature Engineering & Forecast (app/models/track_inference.py)
- Reads historical displacement vectors (past 6h, 12h, 24h lags) and motion angles.
- MultiOutput HistGradientBoosting Regressors predict spatial offsets 
  dLat_24h, dLon_24h, dLat_48h, dLon_48h.
- Calculates projected coordinates, distance in km (Haversine formula), and 
  compass direction heading.

Step 5: API Response Generation (app/api/routes.py)
- Combines Nowcast & Forecast payloads into JSON response and saves transaction 
  record to SQLite database history.

7. STEP-BY-STEP ACCURACY CALCULATION MATH
-------------------------------------------
1. 3-Hour Timesteps: Data is logged every 3 hours. 24h forecast targets row 
   (t + 8 steps). 48h forecast targets row (t + 16 steps).
2. Haversine Distance Formula: Real-world distance error in kilometers is 
   calculated using:
   d = 2 * R * asin(sqrt(sin^2(dLat/2) + cos(Lat1)*cos(Lat2)*sin^2(dLon/2)))
   where R = 6371.0 km.
3. Median Distance Error: 50th percentile of distance errors across all test 
   samples (98.89 km at 24 hours).
